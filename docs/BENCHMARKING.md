# Benchmarking

No savings percentage ships with project. Measure representative tasks against fixed-profile baselines with identical acceptance checks. Record selected profile, total input/output/reasoning consumption, classifier overhead, retries, latency, tool count, failures, and verified outcome.

Calibrate suitability separately from economics. Split evaluation data from tuning data. Report distributions and failure cases, not only averages. Treat self-reported model success as insufficient. Never run live benchmark suite by default or in public CI.
